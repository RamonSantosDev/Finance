💰 FinanX

A FinanX é uma empresa fictícia do segmento financeiro, criada para representar uma plataforma de soluções de crédito por meio de uma landing page moderna, responsiva e intuitiva.

O projeto foi desenvolvido com foco em design, experiência do usuário (UX), responsividade e desenvolvimento front-end, apresentando de forma clara os principais serviços e soluções financeiras da marca.

🌐 Demonstração

🔗 Acesse o projeto:

📋 Sobre o projeto

O projeto consiste no desenvolvimento de uma landing page completa para uma empresa fictícia de serviços financeiros.

A interface foi planejada para transmitir credibilidade, segurança e profissionalismo, utilizando uma estrutura visual organizada e chamadas para ação para proporcionar uma experiência simples e intuitiva ao usuário.

🎨 Design e experiência

O design foi desenvolvido buscando equilibrar estética, clareza e usabilidade, utilizando uma identidade visual voltada ao segmento financeiro.

A organização das seções foi pensada para facilitar a navegação e apresentar as informações de maneira objetiva, proporcionando uma experiência agradável em diferentes dispositivos.
